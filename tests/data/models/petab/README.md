# PEtab test problems

- `benchmark/`: published models of the PEtab benchmark collection
  (https://github.com/Benchmarking-Initiative/Benchmark-Models-PEtab), BSD 3-Clause, see
  `benchmark/LICENSE`; the simulated data and visualization tables are left out.
- `v2/`: cases of the PEtab v2 test suite (https://github.com/PEtab-dev/petab_test_suite),
  BSD 3-Clause, see `v2/LICENSE`; the simulation and solution tables are left out.
