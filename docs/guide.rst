User guide
==========

The user guide shows how a model is formulated, analyzed and reduced with symident. Each
chapter introduces its examples where they are used; the first chapters follow one running
example, a precursor that is made on a stimulus and becomes an observed product.
:doc:`method` gives the mathematics behind each step, and :doc:`api` the full signatures.
